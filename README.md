The project is forked from https://github.com/pranta-barua007/yolo11-onnx then customized to domain niche

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started with Bun

First, install dependencies:

```bash
bun install
```

Then run the development server:

```bash
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Static Export & GitHub Pages

To test the production static export locally:

```bash
bun run build
```

The exported site is placed in `./out` and automatically deployed to GitHub Pages via `.github/workflows/deploy.yml` on push to `main`.
